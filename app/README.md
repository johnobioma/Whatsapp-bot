# Digital Waiter WhatsApp Bot

AI-powered restaurant digital waiter.

## Features

- Customer name collection
- Customer memory
- Food recommendations
- Food ingredient explanations
- Food preparation explanations
- Customer preferences
- Smart negotiation
- Loyalty discounts
- Minimum ₦1,000 price protection
- Order IDs
- Customer addresses
- Payment methods
- Manager notifications
- Delivery updates
- Customer delivery confirmation
- Voice-note understanding
- 20-minute manager reminders
- SQLite persistent storage

## Run

From the project root:

```bash
uvicorn app.main:app --reload --port 8000
